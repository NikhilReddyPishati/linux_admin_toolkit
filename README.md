# Linux Admin Toolkit

A linux Administration Toolkit built using Bash Scripting to automate common system administration tasks.

## Features
- System Information
- User Management
- Service Management
- Health Check
- Memory Monitoring
- Disk Monitoring
- Backup Utility
- Project Setup Automation
- Logging

  ## Technologies Used
  - Bash Shell
  - Linux
  - Git
  - GitHub
